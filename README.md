# 💻 Tecnología de Desarrollo IDE - Ejercicios y Laboratorios

Repositorio correspondiente a la materia **Tecnología de Desarrollo IDE**, cursada como **materia electiva durante el año 2026**.

En este repositorio se encuentran resueltos los ejercicios, prácticas y laboratorios realizados a lo largo de la cursada, organizados según:

- 📚 Capítulos
- 🧩 Unidades
- 🧪 Laboratorios
- 📝 Ejercicios prácticos

---

## 📖 Objetivo del Repositorio

Este repositorio funciona como:

- Material de Estudio
- Registro de avance de la materia
- Práctica de programación C#
- Base de ejercicios resueltos y laboratorios

## 🛠️ Tecnologías Utilizadas

- **Lenguaje:** C#
- **IDE:** Visual Studio 2022
- **Framework:** .NET 8.0

El desarrollo de todos los proyectos y ejercicios fue realizado utilizando el entorno de desarrollo de Microsoft Visual Studio 2022 junto con la plataforma .NET 8.0.
